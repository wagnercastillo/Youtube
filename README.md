# Youtube

Producción del canal de YouTube Shorts **Puro Chisme** (@PuroChismeAnimado): historia y curiosidades contadas como chisme.
Cada episodio en `episodios/epNN-*` es un proyecto HyperFrames (guion → voces ElevenLabs → animación → subtítulos → render).
Ver `CLAUDE.md` para el pipeline completo.
